# Portfolio asset checklist

No application screenshots, client logos, portraits or social accounts are published by default. Add approved assets only after confirming that they are public-safe.

For each project approved for publication, provide:

- A public title, short description and explicit publication state.
- One landscape thumbnail (recommended 1600×1000) and descriptive alt text.
- Optional desktop, mobile and tablet screenshots with verified captions.
- Optional architecture diagram, device mockup or video with rights confirmed.
- Verified public website or demo URL, if appropriate.
- Verified outcomes only—never inferred metrics or client claims.

For the studio, optionally provide a founder portrait, approved biography, CV file and verified social links. Configure a real sending provider before enabling contact delivery.
