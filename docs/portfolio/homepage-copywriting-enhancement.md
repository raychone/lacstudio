# Homepage copywriting enhancement

Date: 2026-11-12. Scope: homepage content and its local homepage-only layout rules. The hero, featured work, navigation, footer, imagery, pricing data, contact form, SEO configuration and other pages are unchanged.

## Why this change

The existing homepage already explained the studio's product and technical scope. This refinement makes the client outcome clearer: what kind of problems can start a project, what practical work is included when needed, and how direct collaboration affects delivery.

## Copy changes (English source)

### What LAC Does

| Card | Before | After |
| --- | --- | --- |
| Start with the right problem | Turn an early idea, a manual process or a confusing customer journey into a focused plan for what to build first. | Turn an early application idea, a manual process or a difficult customer journey into a clear first product direction. |
| Build the product | Create web applications, mobile workflows, client portals, booking tools, dashboards and SaaS products from end to end. | Design and build the custom software people need for customer work and internal operations, from interface through application logic. |
| Connect the work | Bring together backend services, databases, permissions, automation and integrations so the product supports the operation behind it. | Bring backend services, data, permissions and integrations together so disconnected tools become one workable system. |

### New compact section

**What you get from working together** is placed between What LAC Does and How We Build. It presents five scoped outcomes: a clear direction, software built around needs, real functionality, direct collaboration and a defined delivery. A restrained text link leads to the existing Pricing page for indicative starting prices.

### Independent by Design and final CTA

- Added: “That continuity keeps context close, reduces communication overhead and supports clearer product decisions.”
- Final CTA body now welcomes both a clear specification and an early idea, while retaining the existing heading and CTA.

## Localization

All new and revised homepage copy is supplied in English, French, Romanian and Spanish. Meanings are adapted for each locale rather than translated word-for-word.

## Layout notes

- The new section uses a compact five-item, two-column grid that collapses to one column on small screens.
- Each visual system receives its established material treatment: tactile raised panels, nocturne dark surfaces, editorial rules, brutalist outlines and playground rounded geometry.
- Existing motion behavior is preserved; the added rules introduce no animations and inherit the site's reduced-motion contract.
