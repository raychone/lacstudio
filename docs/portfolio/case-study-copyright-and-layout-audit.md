## Layout implementation notes

- Each study now follows one product narrative: overview, technical evidence, concise attribution, sequential navigation, then final contact CTA.
- Attribution is a subdued, design-specific panel. It has intentional whitespace before and after it, avoiding the previous Tactile placement immediately against the final conversion area.
- Previous/next navigation is rendered once near the conclusion. It preserves locale and active design query; the back link returns to the localized Work index.
- The case-study body uses localized project fields for all four supported locales. The footer is untouched.
